# Booking Platform — MERN Frontend

### React Booking Application

The frontend of an earlier MERN-based Booking.com-style project, demonstrating accommodation discovery, search, listing and reservation-oriented interfaces.

## Engineering Focus

- React and React Router
- Reusable component architecture
- Search and filtering flows
- Booking-oriented UI state
- Responsive interfaces
- API-driven frontend patterns

## Portfolio Note

Private authentication, payment implementation and other sensitive integration code have been removed from the public version. The repository is retained as evidence of the earlier MERN implementation that preceded the later Next.js version.
